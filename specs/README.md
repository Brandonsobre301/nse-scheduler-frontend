# Specs

This folder holds per-feature specs. Project-wide standards live in [SPEC.md](../SPEC.md)
at the repo root — read that first.

## Creating a new spec

1. Copy [`_TEMPLATE.md`](./_TEMPLATE.md) to `<kebab-case-feature-name>.spec.md` in this
   folder.
2. Fill in Code Spec and Test Suite before/alongside implementation.
3. Implement, test, then walk the Validation Checklist.
4. Update the spec if the implementation diverges from the plan — it should always
   reflect reality.

## Naming

`specs/<kebab-case-feature-name>.spec.md`, e.g. `specs/estimate-ai-infer-toggle.spec.md`.
